# Manai Data Tools

Excel and CSV automation for small businesses.

I'm Amine, a France-based developer working on data cleaning,
file consolidation, and reporting workflows.

## What I can help with

- Clean duplicates and inconsistent formats.
- Merge Excel or CSV files into a structured dataset.
- Flag missing values and data inconsistencies.
- Automate recurring transformations and summary reports.

## How I work

We agree on the input files, processing rules, and expected output.
Deliverables include the processed files, a summary of changes,
and instructions for running any automation.
